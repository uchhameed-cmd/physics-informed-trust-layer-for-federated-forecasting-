# Data provenance and redistribution

The files under `citylearn_challenge_2022_phase_all/` and `raw/` are from the
**CityLearn Challenge 2022** data set:

> K. Nweye, S. Sankaranarayanan, Z. Nagy, *The CityLearn Challenge 2022*,
> Texas Data Repository, V1 (2023). doi:10.18738/T8/0YLJ6Q

They are redistributed here unmodified, for reproducibility of the
accompanying paper. They are **not** covered by this repository's MIT licence.

**Authors: confirm the data set's redistribution terms before making this
repository public.** If redistribution is not permitted, delete `data/` and
replace it with a download script; `qtrust/data.py` reads the files by name
from that directory and needs no other change.
